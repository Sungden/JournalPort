# ADR-022: Source authority and provenance

Status: Accepted for M7

Source priority is article-type guidance, journal instructions, publisher policy, official portal documentation, and official templates/checklists. Search results are navigation only. Authority is bound to an HTTPS host and an explicit publisher/journal/portal relationship, never inferred from wording. Equal-authority conflicts remain `CONFLICTED`; third-party sources cannot support executable candidate rules.

Snapshots retain URL, retrieval state, content type/status, timestamp, title, and content hash. EvidenceUnits retain minimal text, locator, authority, and their own hash.
