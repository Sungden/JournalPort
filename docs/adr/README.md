# Architecture decision records

ADRs 001–024 record canonical models, parsers, profiles, compliance, transformation, independent
verification, packaging, guideline extraction, provenance, draft safety, and prompt-injection
policy. ADR-025 freezes repository/sdist-only Agent Skill distribution. ADR-026 freezes bundled,
pinned, offline profile distribution for 0.1.0rc1.

Every ADR contains status, context/decision rationale, and consequences either as explicit sections
or as a concise decision narrative. Accepted decisions are changed by a superseding ADR, not by
silently rewriting their historical outcome.
