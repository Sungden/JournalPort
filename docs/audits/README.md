records, not user instructions or current product documentation.

- `M0_AUDIT.md` through `M8_AUDIT.md`: architecture and implementation milestones
- `M9_AUDIT.md`: release-candidate engineering audit
- `M9_5_HOSTING_AUDIT.md`: public-hosting and CI provenance
- `M9_6_RELEASE_AUDIT.md`: `v0.1.0rc1` release provenance and artifact hashes
- `RC2_REAL_MANUSCRIPT_AUDIT.md`: real-DOCX verification and Abstract parsing regression audit
- `RC2_3_REAL_DOCX_STRUCTURE_AUDIT.md` and `RC2_4_FLATTENED_FRONT_MATTER_AUDIT.md`: conservative
  front-matter compatibility follow-ups
- `M10_CONFIDENTIAL_TRANSFORMATION_EXECUTOR_AUDIT.md`: local-only approved transformation audit
