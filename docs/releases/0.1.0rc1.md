# JournalPort 0.1.0rc1

First release candidate with a deterministic parse → audit → plan → apply → verify → package core,
independent candidate/package verification, provenance-backed profile resolution, and four reusable
Agent Skills. Three Article profiles are included, all explicitly `PARTIAL`.

The frozen M7 curated three-journal extraction benchmark reports precision 100%, recall 90.48%, F1
95.00%, and hallucinated-requirement rate 0%. These results do not generalize beyond that fixture
set or evaluate live-provider variance.

Known limitations include partial journal coverage, deliberately narrow safe transformations,
manual author artifacts, no submission automation, no hosted-provider requirement, and no claim of
guaranteed compliance or journal endorsement.
