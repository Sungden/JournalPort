# JournalPort 0.1.0rc1

Canonical repository: <https://github.com/Sungden/JournalPort>

JournalPort 0.1.0rc1 is the first public release candidate of a provenance-aware, verifiable, and
content-preserving infrastructure for journal transfer and submission compliance.

## What it provides

The deterministic architecture is:

```text
Official guidelines
→ provenance-backed profiles
→ manuscript audit
→ approval-gated transformation
→ independent verification
→ submission package
```

It includes structured DOCX/LaTeX parsing, deterministic compliance evaluation, approval-gated
safe transformations, content-preservation verification, and auditable submission-package
generation.

Four Agent Skills orchestrate the tested deterministic core; they do not replace compliance or
verification logic:

- `journal-profile`
- `journal-audit`
- `journal-transfer`
- `submission-package`

## Current profile scope

Initial curated profiles:

- Nature Communications — Article — `PARTIAL`
- Nature Computational Science — Article — `PARTIAL`
- Nature Machine Intelligence — Article — `PARTIAL`

`PARTIAL` is deliberate: this release does not claim complete support for Nature journals.

## Guideline-extraction benchmark

On the initial curated three-journal guideline-extraction benchmark:

- Precision: 100%
- Recall: 90.48%
- F1: 95.00%
- Hallucinated requirement rate: 0%

These results are limited to the initial curated three-journal benchmark and should not be
generalized to arbitrary journals or publishers.

## Installation

Download the wheel or source archive from this pre-release and install it with pip, for example:

```bash
python -m pip install journalport-0.1.0rc1-py3-none-any.whl
journalport --version
```

Expected version output: `journalport 0.1.0rc1`.

## Known limitations

- Only three initial journal/article profiles are included, and all production profiles remain
  `PARTIAL`.
- Complex DOCX/LaTeX structures may be unsupported.
- Semantic rewriting is not automatically executed.
- Conditional or unknown requirements require human review.
- The guideline-extraction benchmark is small.
- Real-LLM provider variability has not yet been benchmarked.
- Submission-portal automation is not included.
- PyPI and Zenodo publication have not occurred.

## Citation

Citation metadata is provided in `CITATION.cff`. The software author is `Sungden`; no public email,

## Security and privacy

Do not submit private manuscripts to untrusted services. JournalPort's core can run locally, but a
public security contact is still pending and this release does not claim a complete production
security-response infrastructure.

## Pre-release warning

This is a release candidate for public evaluation, not a stable or production-ready release.
Interfaces, profiles, and packaging may change before `v0.1.0`.
