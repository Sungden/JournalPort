# Nature Communications DOCX formatting

The reference workflow supports Article DOCX in REVISION and FINAL_SUBMISSION with pinned profile
1.3.2. INITIAL_SUBMISSION remains flexible. ACCEPTED has unresolved stage targets and cannot inherit
revision obligations silently. Historical profiles remain unchanged.

```powershell
journalport full-format manuscript.docx --journal nature-communications --stage REVISION `
  --profile-version 1.3.2 --plan-only --output private/nc-plan

journalport full-format manuscript.docx --journal nature-communications --stage REVISION `
  --profile-version 1.3.2 --reviewed-plan private/nc-plan/metadata/full_format_plan.json `
  --output private/nc-output
```

Use a fresh ignored directory for each run. The plan includes resolved document targets, per-field
provenance, stage, article type, operations, dependencies, expected deltas, manual requirements and
coverage. Core regenerates and compares the complete reviewed plan before execution. No scientific
prose is generated by this command. Missing factual declarations are author inputs.

Output contains manuscript/, figures/, supplements/, metadata/ and package/. The M12 artifact
contract also retains figures under manuscript/figures/ for independent verification. Package files
have checksums. An optional `--supplement FILE` copies one author-supplied DOCX/PDF with a hash-bound
inventory. Unsupported embedded supplements require manual investigation.

Namespace-preserving structural execution retains original runs, images, tables, equations, metadata
and scientific-section order. Explicit front-matter labels or semantic styles support inline identity
reordering; unclassified front matter is author input. Caption text is moved only with reliable existing mappings. Missing
captions are never generated. Known administrative blocks outside the target order block reordering.
An existing footer blocks automatic footer replacement.

Only verified target properties change. Margins, paper size, font family/size and caption delimiters
remain untouched when unspecified. Semantic roles describe document paragraphs independently of
arbitrary source style names. Title-page identity inference and general Nature reference
rendering are still unsupported; numeric linkage and lossless reference-subset identity checks are
available without enrichment. Profile 1.3.2 additionally enables conservative HIGH-confidence reference
rendering as described below; unrestricted conversion remains unsupported.

LibreOffice is optional and is not bundled. `--render-executable PATH` selects a local supported
renderer. NOT_AVAILABLE requires manual visual validation. Headless conversion cannot observe a Word
repair dialog, and table appearance needs visual review; the report keeps these warnings explicit.
Content preservation, target-format coverage, visual status and package readiness are separate.
NC_DOCX_NOT_CLOSED remains the readiness conclusion until every closure gate passes.
# Windows rendering prerequisite

Install LibreOffice locally from its official installer (it is not bundled by JournalPort).
The default Windows executable is `C:\Program Files\LibreOffice\program\soffice.exe`.
Alternatively set `JOURNALPORT_LIBREOFFICE_PATH` to an existing executable, or pass the
existing `--render-executable` option. Explicit configuration takes precedence; a missing
configured executable fails closed rather than falling back to another installation.
Validate the executable with `soffice.exe --version`, then rerun the synthetic render E2E.
Discovery or unit tests alone do not establish RENDER_PASS or VISUAL_PASS.

## HIGH-confidence reference rendering and independent closure coverage

Pin `--profile-version 1.3.1` to select the immutable verified reference presentation target;
1.3.0 is retained unchanged. Rendering supports a conservative journal-article subset with
identity reparsing, protected DOI/author/title/year checks, and numeric citation linkage.
Uncertain records, six-or-more-author elision, unresolved abbreviations and live citation fields
remain manual. No bibliographic enrichment occurs. Source abbreviation correctness still needs
manual confirmation; preserving its text does not prove editorial correctness.

`formatting_target_coverage` counts only audited closure-critical formatting targets, in percent.
`overall_profile_coverage` remains separate. `nc_closure_blockers.json` tracks target and validation
gates. Actual render success and hash-bound full-page visual receipts are distinct requirements;
missing or stale visual evidence cannot close the candidate. The conditional-order synthetic fixture
with supplied statements and conforming references reaches 100% formatting coverage and RENDER_PASS;
this does not establish closure for arbitrary manuscripts.

## Author-confirmed conditional ordering

If the author confirms that custom code or mathematical algorithms are central to the conclusions,
add `--confirm-condition availability.placement` to **both** the plan-only and execution commands.
This records applicability in the hash-bound plan; it does not insert or invent statements.
Unknown rule IDs are rejected. Omitting confirmation keeps the conditional rule blocked for author input.

```powershell
journalport full-format private/manuscript.docx --journal nature-communications --stage REVISION `
  --profile-version 1.3.2 --confirm-condition availability.placement `
  --plan-only --output private/nc-plan

journalport full-format private/manuscript.docx --journal nature-communications --stage REVISION `
  --profile-version 1.3.2 --confirm-condition availability.placement `
  --reviewed-plan private/nc-plan/metadata/full_format_plan.json --output private/nc-output `
  --render-executable 'C:\Program Files\LibreOffice\program\soffice.exe'
```

Before executing, inspect `metadata/full_format_plan.json`: missing declarations require author input;
unreliable headings, uncertain references and unsupported targets remain manual. For this ordering
operation, Data Availability, Code Availability and References must already have unique reliable headings
and nonempty bodies. No scientific writing or bibliography enrichment is performed. Reference rendering
is blocked in a plan that also needs the conditional move, so References body remains unchanged.

The output is a **candidate**, not automatic submission readiness. Verify preservation and coverage,
inspect every rendered page and validate package integrity independently. Packages with outstanding
requirements remain manual-review drafts. Headless rendering cannot certify absence of a Word repair dialog.
