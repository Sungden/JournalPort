# Install the JournalPort journal-transfer Skill

1. Install JournalPort Core `>=1.0.0rc1,<2` into the Python environment used for journal work.
2. Copy this entire `journal-transfer` directory into the configured personal Codex skills directory.
3. Refresh or restart Codex skill discovery.
4. Confirm `journalport --version` and ask Codex to read this Skill before a transfer.

The Skill structure is portable, but only Codex has been validated for this release candidate.
Second-host validation is pending. Keep all manuscript runtime output in ignored private directories.
