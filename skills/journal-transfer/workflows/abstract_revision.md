# Abstract revision

Disclose only the current abstract, its count, target limit/journal, and provenance-backed rule. Ask the
model for a proposal, never an edit. Reject unsupported claims and new methods/results. Run deterministic
word counting and `ScientificDiffReport`; protected token changes make risk HIGH and require explicit
explanation. Show original/proposed text, rationale, counts, and every warning. After explicit approval,
bind the payload through M10 `REPLACE_ABSTRACT`. Never apply automatically.
