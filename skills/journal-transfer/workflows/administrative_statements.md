# Administrative statements

Missing Author Contributions and Competing Interests always require explicit author facts. Offer a
CRediT template but never infer roles or default to “no competing interests.” Inspect existing text for
Data/Code Availability; if it is insufficient, ask the author and never invent repositories, accessions,
or URLs. Normalize only supplied facts as a proposal, approve it, and use M10
`INSERT_REQUIRED_SECTION` or `NORMALIZE_SECTION_HEADING`. Unsupported operations go to manual review.
