# Nature-oriented full rewrite

Use nature-rewrite only for an explicit request to rewrite scientific prose. Determine the target journal and Article type. Configure a local or approved remote OpenAI-compatible model; disclose that remote use transmits manuscript content, and never choose a provider implicitly. Use the CLI with a fresh private output directory. Core generates a source-bound proposal, checks coverage/numeric citations/opaque objects and runs a separate semantic review call. If blocked, inspect the reason and ask for missing author facts; never fabricate results. Deliver DRAFT_REQUIRES_AUTHOR_REVIEW with original/proposed text and semantic review. Explain that model review cannot prove scientific equivalence. Author approval and stage-specific formatting/render/package checks are still required before final delivery as a verified submission candidate.
