# Public synthetic transfer example

This is the single public end-to-end example for JournalPort v1. It contains generated names,
numbers, figures, tables, equations, references, and citations only. It is safe for repository and
release distribution and contains no real manuscript material.

Only the generator source and instructions are distributed. Generated DOCX, images, reports and
packages remain ignored local outputs; run the command below to reproduce them.

The example demonstrates a REVISION-stage verified figure-extraction target, its transfer matrix,
deterministic plan, transformed candidate, independent verification, package build, and package
integrity verification. Rebuild it from the repository root with:

```powershell
python examples/public-synthetic/build_example.py
```
